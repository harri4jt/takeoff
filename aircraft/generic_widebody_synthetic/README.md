# Generic Widebody — SYNTHETIC DATA

> **These are not real-aircraft data.** Every number in this folder was invented to give
> plausible big-jet magnitudes so the solver and the demo work. Do not cite these results
> as the performance of any real airplane.

## How the data were made
All tables are generated by [`tools/make_synthetic_widebody.py`](../../tools/make_synthetic_widebody.py):

* **Lift (`aero_takeoff.csv`):** `CL = CL0 + CLα·α` with CL0 = 0.55 and CLα = 0.09 /deg,
  smoothly capped at about 1.90 by a log-sum-exp soft minimum. Past α = 15° there is a
  quadratic post-stall drop. The table CLmax (≈1.87) is what the solver uses.
* **Drag:** a parabolic polar `CD = 0.040 + 0.060·CL²` plus a post-stall rise.
  It represents takeoff flaps with the gear down. There is no ground effect.
* **Thrust (`thrust.csv`):** per engine, `50,000·(1 − 9e-4·V + 1.2e-6·V²)` lbf with V in kt.

## Chosen scalars (`aircraft.yaml`)
| Item | Value |
|---|---|
| Wing area | 5,500 ft² |
| Default weight | 775,000 lbf |
| Engines | 4, idle 1,500 lbf each |
| Tail-strike attitude | 12.5° (target 11.5° after the 1° margin) |
| Engine-out ΔCD | 0.0040 |
| Spoilers ΔCL / ΔCD | −0.60 / +0.070 |
| Chute (off by default) | 1,500 ft², CD 0.60, 1 s delay, 1 s inflation. A demo only, outside Part 25. |
